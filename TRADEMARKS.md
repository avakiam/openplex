# OpenPlex trademark policy

> **Draft.** Español: [docs/es/licensing.md](docs/es/licensing.md#marca) ·
> Català: [docs/ca/licensing.md](docs/ca/licensing.md#marca)

The OpenPlex source code is free software (see `LICENSE`). The name
**OpenPlex** and the OpenPlex logos are not: they identify the official
project and its official extensions, and the licence does not grant any right
to use them.

## Allowed without asking

- Saying truthfully that your product or service uses, runs on, or is
  compatible with OpenPlex ("Hosting with OpenPlex", "an extension for
  OpenPlex").
- Offering an **unmodified** official release of OpenPlex under its name, for
  example as a server image or a one-click install at a hosting provider.
- Writing articles, tutorials, videos and talks about OpenPlex.

## Not allowed without written permission

- Calling a **modified** version of OpenPlex "OpenPlex", or using a name or
  logo that could be confused with it (for example "OpenPlex Pro").
- Presenting an extension as official, made or endorsed by the OpenPlex
  project when it is not.
- Using OpenPlex in a company, product or domain name.

A modified version must use a different name and logo, and may say that it
is "based on OpenPlex".

To ask for permission, open an issue in the main repository or write to the
address in `SECURITY.md`.
